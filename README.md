# 🌾 Farmer's Market

A web-based platform that connects **farmers** directly with **merchants**, enabling transparent and efficient buying and selling of agricultural products. The system eliminates unnecessary intermediaries, allowing farmers to receive better prices while helping merchants purchase fresh produce directly from the source.

📌 Features

* 👨‍🌾 Farmer Registration and Login
* 🛒 Merchant Registration and Login
* 🌱 Product Listing and Management
* 🔍 Browse Available Agricultural Products
* 📦 Place and Manage Orders
* 📊 User Dashboard
* 🔐 Secure Authentication
* 📱 Responsive User Interface

🚀 Installation

1. Clone the repository
git clone https://github.com/tanvidongare63/Farmer-s-Market.git

2. Navigate to the project
cd Farmer-s-Market

3. Create a virtual environment

**Windows**
python -m venv venv
venv\Scripts\activate

**Linux / macOS**
python3 -m venv venv
source venv/bin/activate

4. Install dependencies
pip install -r requirements.txt

5. Configure the database
* Create a MySQL database.
* Update the database credentials in your configuration file.
* Import the required SQL tables if applicable.

6. Run the application
python app.py
